## Environments

Four interpreters in play for one repository:

| venv | Claims | Actually runs | Notes |
|---|---|---|---|
| `.venv` | 3.13.9 | 3.13.9 | healthy; matches `requires-python` |
| `alpha-go/.venv` | **3.12.13** | **3.14.6** | `pyvenv.cfg` misreports its own version |
| `alpha-go/.venv312` | 3.12.13 | 3.12.13 | the README-prescribed env; missing pytest + 6 core deps |
| `~/.venvs/alpha-go` | 3.11.13 | 3.11.13 | **outside the repo**; used by both soft's launchd job and earnings |

System `python3` is 3.14.6, which violates the root project's declared
`requires-python = ">=3.13,<3.14"` — so every README command written as
`python3 ...` used an unsupported interpreter.

Undeclared but imported at module scope: `pandas`, `openpyxl`. Declared pins had
drifted from installed versions on 4 of 6 packages.

## Vendored forks

`--sync` is `rmtree` + `copytree` in both subprojects, and `--check` never
actually compared anything. Drift at baseline: **soft 16 files**, **alpha-go 36
files**. alpha-go additionally had no net-new protection, so a sync would have
deleted `src/download/edgar.py` — its SEC EDGAR adapter, which has no counterpart
in root.
